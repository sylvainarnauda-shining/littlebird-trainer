# LittleBird Trainer {{version}} — préversion

LittleBird Trainer est un entraîneur **hors ligne** de pilotage et de tir pour hélicoptère léger armé (type AH-6M à
miniguns). Son modèle de vol, sa souris, sa caméra, son HUD et ses sons sont calés sur des mesures faites sur deux
enregistrements de parties de WARDOGS, pour s'entraîner à ses sensations sans lancer le jeu. Projet non officiel, créé
par un joueur pour les joueurs : il n'est **ni affilié, ni approuvé, ni soutenu** par les éditeurs ou les développeurs
du jeu. Il ne contient aucun fichier du jeu, fonctionne hors ligne et n'envoie aucune donnée.

## Nouveautés de la {{version}}

La version {{version}} est une **préversion** (_pre-release_) : le vol, les modes (stand de tir, assaut, défense sol-air,
partie réelle, tours, vol libre, duel contre des bots), les cartes et les réglages sont complets et testés, mais les
menus sont encore ceux de l’entraîneur. Les **menus fidèles au jeu** (choix du mode et pages de réglages organisés
comme ceux du jeu, touches principales et secondaires) arrivent avec la **version 1.0**. Un profil enregistré (réglages et
touches) est prévu pour y être repris ; le bouton « Exporter le profil » de l’onglet Réglages l’enregistre aussi dans
un fichier.

- **Joysticks.** Vous pouvez piloter avec un ou deux joysticks (prévu pour deux Thrustmaster T.16000M FCS ou pour un
  manche virtuel vJoy alimenté par un logiciel de fusion ; les tests utilisent des manettes simulées, l’essai avec de
  vrais manches en vol reste à faire) : onglet Commandes, carte « Manette · HOTAS ». Les six axes du
  jeu (tangage, collectif, roulis, lacet, regard libre horizontal et vertical) et les boutons de tir, de leurres et de
  changement de vue se règlent comme dans le jeu, et la section joystick du fichier de réglages du jeu peut être
  importée (aperçu avant, rien n’est envoyé). **Cette page est provisoire** : la réponse des manches (courbes,
  sensibilités) est une base **supposée**, pas encore mesurée dans le jeu, et le clavier et la souris continuent de
  piloter avec le HOTAS activé. Rien n’est lu avant que vous le demandiez (bouton « Lire les manettes », ou en vol
  avec le HOTAS activé).
- **Cabine plus pleine.** Mesurée sur les enregistrements de référence, la cabine du Little Bird garde des flancs
  presque parallèles le long des portes, là où le modèle précédent se resserrait vers l’avant ; elle est élargie
  devant sa section la plus large (1,46 m au plus large, 1,40 m au montant avant). Ça se voit surtout de dessus, de
  trois-quarts et de face. Les impacts sur l’avant de la cabine suivent sa forme.
- **Outillage de test** préparé pour les menus de la version 1.0 (rien de visible).

## Quel fichier télécharger

| Fichier                                         | Pour qui                                                                                           |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `LittleBird-Trainer-Setup-{{version}}.exe`      | Windows 10 ou 11 (64 bits) : installation en un clic pour votre compte, sans droits administrateur |
| `LittleBird-Trainer-{{version}}-win-x64.zip`    | Windows, sans installation : extraire, puis lancer `LittleBirdTrainer.exe`                         |
| `LittleBird-Trainer-{{version}}-navigateur.zip` | Tout système, sans rien exécuter : ouvrir `index.html` dans Chrome ou Edge                         |

Il faut une carte graphique compatible WebGL 2, une souris et un clavier. Détails, profils et désinstallation :
[INSTALLATION.md](https://github.com/{{repo}}/blob/v{{version}}/docs/INSTALLATION.md).

Le numéro de la version (`v{{version}}`) est affiché en haut à droite du menu du jeu et dans son onglet **À propos** :
comparez-le avec la dernière version de la page **Releases** du dépôt ; l'entraîneur ne vérifie rien tout seul et n'envoie
rien. Pour être prévenu des nouvelles versions : **Watch › Custom › Releases** sur le dépôt.

## Avertissements de Windows

Les exécutables **ne sont pas signés** par un certificat d'éditeur. Au premier lancement, **Windows SmartScreen**
affiche « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**, puis sur **Exécuter
quand même**. Ce n'est pas une alerte de virus.

Si le **Contrôle intelligent des applications** de Windows 11 est activé, il peut bloquer l'installateur et
l'application sans proposer de les lancer, parce qu'ils ne sont pas signés et encore peu connus. Ne le désactivez pas
pour ce programme : utilisez alors la **version navigateur** (`LittleBird-Trainer-{{version}}-navigateur.zip`), qui
n'exécute rien et offre le même entraîneur.

## Vérifier les fichiers

- **Empreintes SHA-256** : comparez l'empreinte du fichier téléchargé avec sa ligne de `SHA256SUMS.txt` (aux
  majuscules près : PowerShell les écrit en majuscules). Sous Windows, dans PowerShell :
  `Get-FileHash -Algorithm SHA256 .\LittleBird-Trainer-Setup-{{version}}.exe` ; sous macOS :
  `shasum -a 256 <fichier>` ; sous Linux : `sha256sum <fichier>`, ou, dans le dossier où `SHA256SUMS.txt` est
  téléchargé à côté de vos fichiers, `sha256sum --check --ignore-missing SHA256SUMS.txt` (qui ne vérifie que les
  fichiers présents).
- **Provenance** : chaque fichier porte une attestation signée qui dit que GitHub Actions l'a construit depuis ce dépôt,
  à l'étiquette `v{{version}}`. Avec l'outil GitHub CLI :
  `gh attestation verify <fichier> --repo {{repo}} --signer-workflow {{repo}}/.github/workflows/release.yml`.
  L'installateur porte aussi l'attestation de sa liste de composants (`LittleBird-Trainer-{{version}}.sbom.cdx.json`).
- **Page de la version navigateur** : SHA-256 `{{page_sha256}}`. `npm ci` puis `npm run build` sur l'étiquette
  `v{{version}}` redonnent la même page, octet pour octet.
